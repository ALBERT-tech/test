# rb-report — выгрузка из Bitrix и битриксоподобная HTML-таблица

Два файла, работают на любом Windows без установки чего-либо (нужен только браузер):

- `export-rb-data.ps1` — выгружает данные через тот же API, что и плагин rb-sync, и пишет `rb-data.js`.
- `rb-report.html` — открывается двойным кликом, показывает данные в таблицах в стиле грида Bitrix24: вкладки **Проекты / Процессы / Направления**, фильтры по направлению, площадке и статусу, поиск, сортировка кликом по заголовку, сводка (Всего / Топ 🔥 / Выполняется / Завершено / Просрочено), подсветка просроченных сроков.

## Как пользоваться

1. Положите оба файла в одну папку.
2. Выгрузите данные (тот же базовый URL и ключ, что для check-rb-api):

```powershell
powershell -ExecutionPolicy Bypass -File .\export-rb-data.ps1 https://bitrix.rossilber.com/ПУТЬ/api КЛЮЧ
```

Рядом появится `rb-data.js` (в шапке отчёта видна дата выгрузки).

3. Откройте `rb-report.html` в браузере.
4. Чтобы обновить данные — просто запустите скрипт ещё раз и обновите страницу (F5).

Флаги те же, что у валидатора: `-Insecure` для самоподписанного сертификата, третий аргумент — fallback-IP.

## Как это устроено

- Выгрузчик берёт список направлений (`direction.php?k=`), затем для каждого направления запрашивает `direction.php?k=&id=N` — в ответе уже лежат полные строки процессов (`[1]`) и проектов (`[2]`) со всеми полями для таблиц. Итого ~27 запросов вместо полутора тысяч.
- Страница — статичный HTML без сервера и без запросов в сеть: данные она читает из соседнего `rb-data.js`. Поэтому нет проблем с CORS и её можно открывать с любого диска или пересылать коллегам (вместе с `rb-data.js`).
- Логика статусов повторяет плагин rb-sync: `STATUS == 5` — завершено, `PRIORITY == 2` — топ 🔥, просрочка — `DEADLINE` в прошлом у незавершённого проекта (`new Date()`, нужен ISO-формат `2026-08-20`).

## Ограничение

В отчёт попадает только то, что привязано к направлениям (как и в таблицах Obsidian-плагина). Процесс или проект без направления — например, процесс id=192 из проверки валидатором — в выгрузку не попадёт, пока ему не проставят направление в Bitrix.
